How FDP Works

  • Organizes flash into Reclaim Groups (RGs) and Reclaim Units (RUs) addressed via Reclaim Unit Handles (RUHs) and Placement Identifiers (PIDs).
  • Hosts stamp PIDs directly in write command CDW12 (Directive Type = Data Placement, DTYPE=2h) and CDW13 (DSPEC).
  • vs. ZNS: Retains conventional random-LBA block semantics (no append-only zone reset rewrite of the host stack) while isolating write lifetimes to drive device WAF near 1.0.

Validation Focus

  • Verify RUH Reclaim Unit allocation, Initially Isolated vs Persistently Isolated handles, and FDP Events Log accounting.
  • Test shift-left locally via QEMU NVMe with fdp=on before running hardware RocksDB / CacheLib steady-state WAF comparisons.

OCP Datacenter NVMe SSD 2.6 & 2.7

  • Error Injection (Set Features C0h): 21 explicit fault injection modes.
  • Crash & Recovery: CRASH-5 (<2s FW watchdog timer) & EREC-2 (autonomous panic recovery preferring NVMe Controller Reset).
  • Telemetry SLA: <1 ms typical (<5 ms max) I/O latency impact during 32 KiB DA1 retrieval; >16 Virtual FIFOs across DA1/DA2.
  • Security & 2.7 Delta: Mandatory OCP S.A.F.E. audits (SEC-15), peak/avg power telemetry (PCM-1/2), plus OCP 2.7 offset errata fixes and FIPS 140 status in Log C4h.

Out-of-Band Sideband Stack

  • NVMe-MI 2.1 / 2.2 operating over MCTP (Management Component Transport Protocol).
  • Physical transports: SMBus / I2C, I3C, and PCIe VDM (Vendor-Defined Messages).
  • Validates out-of-band health polling, SMBus data verification, sideband FW activation, and SPDM device attestation.
