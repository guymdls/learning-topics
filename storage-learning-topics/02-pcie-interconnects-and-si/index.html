Bench Diagnostics & EDSFF Form-Factor Envelopes

Separate riser-card SI loss and PCIe link downgrades from SSD controller firmware bugs.

Linux Bench Inspection Workflow

  • lspci -vv -s <BDF> — verify negotiated Speed/Width (LnkSta vs LnkCap), FLIT mode, MaxPayloadSize, and Completion Timeout.
  • AER / DPC: Monitor sysfs AER counters & test recovery via /dev/aer_inject; correlate against OCP SMART PCIe Link Retraining Count & Correctable Error Count.
  • Virtualization & Direct Transfers: Validate SR-IOV PFs/VFs + ARI, P2P DMA hierarchy distance (for CMB & GPUDirect Storage), and PCIe IDE / CMA / DOE link security.
  • Signal Integrity: Use nvmeadm sandisk/pci-eye and check retimer/redriver margin on Gen5/Gen6 risers.
