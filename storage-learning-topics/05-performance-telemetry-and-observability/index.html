USE, TSA & TMAM Profiling

Combine Gregg’s USE (Utilization, Saturation, Errors) and TSA (Thread State Analysis) with Intel TMAM (Front-End, Back-End, Bad Speculation, Retiring) using perf (PEBS/LBR), CPU/Off-CPU Flame Graphs, and bpftrace.

Coordinated Omission Hygiene

Closed-loop generators pause new submissions when a drive stalls, hiding multi-second GC/read-retry hiccups from p99.99. Use open-loop paced traffic, never average percentiles across runs, and never drop max latency.

Apache Otava (Hunter) CI

Eliminates brittle static % regression thresholds on noisy test racks via a modified E-divisive means algorithm (Student’s t-test + overlapping fixed windows) to flag statistically significant firmware/harness regressions.
