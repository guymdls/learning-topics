Databases + FDP

RocksDB, MySQL & Ceph Crimson

Databases write hot logs alongside cold tables. Using NVMe FDP plugins (KIOXIA UFROP, Samsung TorFS, Meta CacheLib) achieved ~1.0 WAF at 90% fill in academic tests and cut XFS tail latency by 55%! At cluster scale, Ceph Crimson / PoseidonStore uses io_uring to eliminate RocksDB overhead.

Networked SSDs (NVMe-oF)

NVMe/TCP vs. NVMe/RoCEv2

NVMe/TCP runs over normal Ethernet (~100–400 μs; scaling -i I/O queues from 8→96 cut latency >42% in Lightbits tests; add kTLS 1.3 for encryption). RoCEv2 uses zero-copy RDMA over UDP 4791 (~20–100 μs) on lossless PFC + ECN/DCQCN switches.

PC & Console Gaming

DirectStorage 1.2+ & GDeflate

Instead of the CPU decompressing game textures one file at a time, DirectStorage + BypassIO batches thousands of compressed reads from SN8100 straight into the GPU for GDeflate decompression (console target: 50k IOPS using ≤10% of 1 CPU core).

Computational Storage

Running Code Inside the SSD

NVMe Computational Programs (TP4091) & SNIA CS-APM v1.2 let hosts offload filters/eBPF onto SSD controllers — promising, though real adoption still awaits unified software ecosystems.

Think of storage security in three clean layers:

1. Lock Data on Flash

TCG Opal 2.30, Ruby & EKP

Hardware AES engine encrypts every NAND page automatically. You validate Level 0 Discovery, LBA Locking Ranges, Shadow MBR pre-boot auth, Block SID, PSID Revert, and instant crypto-erase (plus Aug 2026 Epoch Key Purge).

2. Hide Keys from Firmware

OCP S.A.F.E. & L.O.C.K. v1.1

S.A.F.E. audits FW across 20 security areas. OCP L.O.C.K. v1.1 (Caliptra hardware vault) keeps raw encryption keys out of main SSD firmware, wrapping keys with RFC 9180 HPKE on every reset.

3. Prove Drive Identity & Wire

SPDM 1.4, FIPS 140-3 & PQC

SPDM 1.4 cryptographically proves the SSD hardware & firmware are genuine (and keys PCIe IDE wire encryption). FIPS 140-3 certifies crypto modules, and NVMe 2.4 PQC (FIPS 203/204/205) future-proofs against quantum attacks.
